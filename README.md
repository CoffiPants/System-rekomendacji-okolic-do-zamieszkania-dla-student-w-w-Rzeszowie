# System rekomendacji okolic do zamieszkania dla studentów w Rzeszowie

## Opis problemu
Celem projektu jest opracowanie systemu rekomendacji, który pomoże studentom znaleźć odpowiednie okolice do zamieszkania w Rzeszowie.
